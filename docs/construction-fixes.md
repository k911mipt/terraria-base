## Непрерывность фона

Восстановлены **162 отсутствовавших тайла** декоративных стен на Y11/21/31/41
левой босс-арены. Это не сплошное зашивание открытой арены: добавлены только
соединения уже существовавших стен, продолжавшихся прямо выше или ниже платформ.
Материал каждого соединения взят из соседнего участка, новые краски не выбраны.
44 явно записанных горизонтальных участка находятся в
`js/data/backgrounds/boss-platform-joins.js`; автоматической починки при старте нет.

Все передние блоки, платформенные этажи, ловушки, люки, размеры помещений,
водоёмы и границы сцен сохранены. Изменены только 25 записей объектов
(координаты/высота) и добавлен фон. Порядок остальных объектов и их подробные
описания не менялись.

## Проверки и независимый golden

```sh
node tools/audit-building.cjs
node tools/check-building.cjs
node tools/check-geometry.cjs
python tools/check-browser.py
```

Строгая проверка должна возвращать 0 для всех четырёх сцен. Отрицательные
регрессии по-прежнему возвращают ошибки при удалении стен, опор и т. п.
Снимок геометрии в `tools/fixtures/geometry.json` создан для осознанно исправленного
дизайна, независимо от `D.validation`; это не список ожидаемых нарушений.
Он включает геометрию, порядок, материалы и влияющие на рисунок свойства объектов.
Автоматической команды «обновить golden, чтобы тест прошёл» нет.

Неполные предметные спецификации отдельно продолжаются в #27. Успешная проверка
описанной конструкции не означает, что уже смоделирован весь движок Terraria,
счастье жителей или возможность покупки предметов на любом этапе игры.
