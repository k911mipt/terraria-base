# Пустынный аванпост

`desert.html` — самостоятельная сцена на общем Canvas-движке проекта. Она не соединена координатами с основной базой и не содержит world overview.

## Назначение

- две отдельные комнаты NPC;
- центральный Desert Pylon;
- локальная кровать и минимальный сервис;
- закрытый рыболовный резервуар 20×16, всего 320 тайлов воды;
- пять локальных сундуков;
- прямой безопасный спуск в подземную пустыню.

Сцена намеренно не содержит привязок к расположению Dungeon, боссов или других уникальных структур конкретного мира.

## Геометрия v4

- поверхностный павильон сохраняет ширину 55 тайлов;
- под жилыми комнатами и хабом расположен сплошной Sandstone-фундамент;
- единственная пустота в фундаменте — безопасная сервисная шахта;
- уровни сервисного спуска: `y20 → y27 → y34`, шаг ровно 7 тайлов;
- рыболовный зал занимает `x27…54`, то есть 28 тайлов;
- левая пустая ниша полностью удалена;
- вода занимает `x28…47, y35…50`: ровно `20×16 = 320` тайлов;
- четырёхтайловый проём для заброса расположен на `x36…39`;
- по обе стороны проёма остаётся по восемь Palm Wood Platform;
- сразу после бассейна находятся стеклянная стенка и сервисная площадка `x48…53`;
- одна дверь на `x54, y31…33` открывается прямо на шахту `x55…61`;
- площадки прямого спуска: `y34 / y41 / y48 / y55 / y62 / y69`;
- безопасная фоновая стена закрывает всю показанную шахту.

## Данные

- `js/data/desert/layout.js` — границы, комнаты и инварианты;
- `js/data/desert/solids.js` — павильон, заполненный фундамент, компактный рыболовный зал и платформы шахт;
- `js/data/desert/backgrounds.js` — безопасные стены и окна;
- `js/data/desert/objects.js` — NPC, пилон, мебель, сундуки, вода и освещение;
- `js/data/desert/materials.js` — Sand, Palm Wood и пустынные визуальные расширения;
- `js/data/desert/index.js` и `engineering.js` — сборка сцены.

## Проверка

```bash
node tools/check-desert.cjs
```

Проверка фиксирует два NPC, один пилон, пять сундуков, пять дверей суммарно, 320 тайлов воды, заполненный фундамент, уровни `20/27/34`, прямую шахту и семитайловый шаг всех её платформ.
