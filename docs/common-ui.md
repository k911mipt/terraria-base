# Общий запуск и интерфейс сцен (#32)

`scene-ui.js` явно задаёт отличия четырёх сцен: начальный режим/камеру,
координаты фокуса кнопок, фильтр комнат, скрытые в таблице типы объектов и
наличие инженерии. Общий код не содержит цепочки проверок `sceneId`.

`formatters.js` содержит единственные `biName`, `paintName`, `escHtml`.
`tables.js` строит общие таблицы комнат/материалов и аванпостов; подробный склад
и инженерные таблицы основной базы остаются отдельной функцией. Полные тексты
хранения, порядок строк, состав материалов и вычисляемый аудит сохраняются.

Четыре HTML подключают общие `prepare.js`, `interactions.js`, `start.js`.
Пустые инженерные массивы поддерживаются общим построителем индексов, проверки
ловушек/сердец выполняются только для основной базы. Удалены 12 дублирующих
файлов и девять скрытых кнопок аванпостов. Ссылки четырёх сцен остаются в HTML;
JavaScript больше не дописывает вкладки и не исправляет обработчики постфактум.

Сетевая политика существующего HEAD-probe при объединении не менялась:
недоступный storage/сеть не мешают запуску; согласованная версия ресурсов — #34.

## Проверки

```sh
node tools/check-scene-ui.cjs
node tools/check-geometry.cjs
python tools/check-browser.py
```

HTTP smoke дополнительно нажимает каждую настроенную кнопку и сверяет её
эффект, поиск объекта и возврат камеры. Существующие touch/pan/pinch, инспектор,
96 сценариев и сравнение браузерного аудита с CLI сохранены.

При подготовке PR отдельно сравнены начальные камеры, текст всех четырёх
таблиц и три Canvas-слоя каждого desktop/mobile варианта с исходным `21ce3f3`:
все совпали. Локальное сравнение выполнялось с inlining исходников без HTTP;
проверка отдельных ресурсов остаётся обязанностью настоящего HTTP smoke в CI.
Ни данные сцен, ни geometry golden не обновлялись.
