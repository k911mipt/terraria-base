# Защита main: подготовлено, но ещё не включено (#35)

**Этот файл и зелёный CI не означают, что защита применена на GitHub.** На
10 сентября 2026 `main` имеет `protected: false`, список rulesets пуст.
Подключённая интеграция получила `403 Resource not accessible by integration`
при чтении `branches/main/protection`; операции записи административных правил
в ней нет. Код, ветки, PR и merge при этом доступны.

## Проверенная конфигурация

[`.github/main-ruleset.json`](../.github/main-ruleset.json) — тело создания
дополнительного repository ruleset, строго для `refs/heads/main`. Оно требует PR,
успешный актуальный check **`validate` от GitHub Actions (app ID 15368)** и
разрешённые review-треды; запрещает force-push и удаление main. Обходов нет.

Ни чужой approve, ни approval последнего push не требуются: одиночный владелец
может слить зелёный PR после завершения Code/Security Review. Это организационное
условие review проверяется отдельно; комментарий бота не является status check.
Check/app сверены с реальным успешным check run `102887870565` ревизии `9c85482f`.
`tools/check-merge-policy.cjs` проверяет только содержимое предложения и его
отрицательные контроли, **не сетевое состояние защиты**. Workflow не получает
write-права и не пытается применить этот JSON.

## Применение владельцем через имеющуюся авторизацию gh

Из актуального checkout репозитория сначала просмотреть все существующие правила:

```sh
gh api --paginate repos/k911mipt/terraria-base/rulesets \
  --jq '.[] | {id, name, enforcement, source}'
```

Если `main-validated-pr` уже существует, не создавать дубликат: прочитать его
по ID и сверить. Иные, более сильные правила не удалять и не перезаписывать.
Для первой установки используется отдельный POST, не замена текущей защиты:

```sh
gh api --method POST repos/k911mipt/terraria-base/rulesets \
  -H 'X-GitHub-Api-Version: 2026-03-10' \
  --input .github/main-ruleset.json
```

Команда требует авторизации владельца с `Administration: write`. Не передавать
токен в чат и не помещать его в код или workflow. При 403 не обходить ошибку
через отключение проверок. Ответ с ID сохранить и прочитать активные правила:

```sh
gh api --paginate repos/k911mipt/terraria-base/rules/branches/main
```

Точная схема и требуемые права: [официальный GitHub REST API](https://docs.github.com/en/rest/repos/rules#create-a-repository-ruleset).
