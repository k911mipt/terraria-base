# Terraria Base Planner

Интерактивная схема базы для совместного прохождения Terraria.

## Открыть схему

https://k911mipt.github.io/terraria-base/

## Канонический файл

Актуальная рабочая версия всегда хранится в `index.html`.

История версий хранится в Git-коммитах. Не нужно создавать копии с именами
`final`, `fixed`, `latest`, `v2` и похожими суффиксами.

## Правила изменений

- Один логически законченный набор изменений — один коммит.
- Перед изменением нужно брать актуальный `index.html` из репозитория.
- Чистый рефакторинг не должен менять геометрию, материалы и координаты.
- Не добавлять сборщик, фреймворк или зависимости без реальной необходимости.
