# Terraria Base Planner

Интерактивная схема базы для совместного прохождения Terraria 1.4.5.6.

## Открыть схему

https://k911mipt.github.io/terraria-base/

## Структура проекта

`index.html` — тонкая точка входа. Стили находятся в `styles.css`,
данные базы — в тематических файлах `js/data/`, Canvas-рендерер и интерфейс —
в `js/runtime/`.

Подробная карта исходников: [docs/code-map.md](docs/code-map.md).

## Локальный запуск

Из-за нескольких JavaScript-файлов открывайте проект через локальный HTTP-сервер:

```bash
python3 -m http.server 8000
```

Затем откройте `http://localhost:8000/`.

Проверка данных и критических координат:

```bash
node tools/check-data.cjs
```

## Правила изменений

- Один логически законченный набор изменений — один коммит.
- Перед изменением нужно брать актуальную ветку репозитория.
- Чистый рефакторинг не должен менять геометрию, материалы, координаты и порядок слоёв.
- Массивы собираются в явном порядке; не сортировать их автоматически.
- Не добавлять сборщик, фреймворк или runtime-зависимости без реальной необходимости.
- Не создавать копии с именами `final`, `fixed`, `latest`, `v2` и похожими суффиксами.
